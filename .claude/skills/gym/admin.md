# Импорт истории и пользователи

Читай, когда владелец просит перенести тренировки из другого приложения или завести нового
пользователя.

## Импорт

`gym import <каталог> [--dry-run] [--update]` — папки `plans/`, `workouts/`, `measurements/` в
формате вывода `plan get`, `workout get`, `measure list`. ID — UUIDv5 (ADR 0013), поэтому повтор
безопасен. Сначала запусти `--dry-run`: `differs` — запись на сервере поправлена, и без
`--update` она не меняется. Конвертер Hevy и GymKeeper — `import/hevy_gymkeeper.py` в
репозитории. Выгрузки — личные данные, держи их вне репозитория.

## Пользователи

Только по просьбе владельца: `gym admin user add <email> [--name] --qr` выдаёт первый ключ и
ссылку для телефона, `gym admin user list` — список. Ключ показывается один раз: передай его
владельцу, в отчёт и файлы не пиши.
