# 0002. CLI — тонкий клиент к REST

Дата: 2026-11-01. Статус: принято.

## Решение
CLI `gym` ходит только в REST API. Аналитика (`compare`, `volume`) и текстовые форматы
считаются на сервере, логика — в общем Kotlin-модуле `core`. CLI печатает ответ.

## Почему
Сервер дома за Cloudflare, агент на другой машине — прямого доступа к БД нет. PWA нужна та же
аналитика, поэтому считать её один раз на сервере.
