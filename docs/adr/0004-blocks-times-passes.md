# 0004. Тренировка — блоки × проходы

Дата: 2026-11-01. Статус: принято.

## Решение
План и факт состоят из блоков `[упражнения] × N проходов` с ролью (разминка / основной / заминка).
Отдельной сущности «обычные подходы» нет. Факт подхода хранит (блок, упражнение, номер подхода);
реальный порядок — по отметкам времени. Экран — по упражнениям: разделители между блоками,
карточка раскрывается в список подходов, следующий подход подсвечен, тап по оценке записывает его.

## Почему
Одна модель для кругов, суперсетов и обычных подходов упрощает экран, сравнение и текстовый
формат. Круги — основной сценарий. Вид «по проходам» при необходимости — переключатель, модель
та же.

## Уточнение (2026-11-01): что первично

Первичны списки целевых подходов у каждого упражнения блока. «N проходов» — длина самого
длинного списка, нужна для заголовка. Проход k — подходы с номером k у всех упражнений, у
которых такой есть, так что круг может быть неровным. Текущий проход — наименьший номер с
невыполненным подходом. В свёрнутой карточке — первый невыполненный подход упражнения. Отдых
после отметки: если проход закрыт — отдых после прохода, иначе — после упражнения.
