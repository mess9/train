# 0005. Агент работает с JSON

Дата: 2026-11-01. Статус: принято.

## Решение
Агент и пишет, и читает JSON: планы отправляет по схеме OpenAPI (сервер валидирует), историю,
`compare` и `volume` получает тоже JSON. Своего текстового DSL и текстового рендера нет.

## Почему
Агенты надёжно пишут и разбирают JSON по схеме. Парсер DSL с сообщениями об ошибках и отдельный
текстовый формат — лишняя работа и источник багов. Если история перестанет влезать в контекст —
сначала компактнее JSON (фильтры, периоды), а не новый формат.
