# Глоссарий train

Термины предметной области. Код, API и документы используют эти слова в этом значении.
Решения — в `docs/adr/`, концепция — в `DESIGN.md`.

| Термин | Значение |
|---|---|
| **Запланированная тренировка** (план) | Конкретная сессия на дату, сгенерированная агентом. Дата — намерение: начать можно в любой день. До старта агент правит план, каждая правка — новая **версия**; после старта план заморожен. Не начатый в срок — «просроченный», судьбу решает агент. Программы-шаблона нет. |
| **Тренировка** (факт) | То, что владелец реально сделал. Может ссылаться на план. Одна активная за раз. |
| **Снимок плана** | Копия целей той версии плана, с которой началась тренировка. Подходы и `compare` опираются на снимок, а не на текущий план. |
| **Блок** | Часть тренировки: упражнения блока, каждое со своими целевыми подходами, + роль. Число проходов — длина самого длинного списка подходов. Обычные подходы 3×10 — блок из одного упражнения × 3; суперсет — блок из двух; круг — из нескольких. |
| **Роль блока** | Разминка / основной / заминка. Свойство места в тренировке, не упражнения: любое упражнение можно поставить в любой блок. |
| **Проход** | Подходы с одним и тем же номером у всех упражнений блока. Круг может быть неровным: упражнения с двумя подходами в проходе 3 нет. Текущий проход — наименьший номер, где осталось невыполненное. Проход закрыт, когда выполнены все подходы с этим номером. |
| **Подход** | Единица записи: значения + оценка + заметка + отметка. Факт хранит (блок, упражнение, номер подхода), ссылку на целевой подход, если был, и **свои** упражнение, тип записи и «на сторону» — его смысл не меняется при правке раскладки или справочника. Вес — одного снаряда (одной гантели), повторы «на сторону» — на каждую сторону. |
| **Целевой подход** | Что предложено в плане. Число подходов, веса, повторы, пирамиды — любые, задаются при создании и меняются при заполнении. |
| **Тип записи** | Что измеряется: `вес × повторы`, `повторы` (+ доп. вес), `время`, `вес × время`; флаг «на сторону». У упражнения — тип по умолчанию, в плане и тренировке меняется на месте (скакалка: время ↔ прыжки); уже сделанные подходы сохраняют свой тип. |
| **Снарядов** | Сколько снарядов в упражнении: 1 или 2 (две гантели). |
| **Доля веса тела** | Какую часть собственного веса поднимаешь в повторе: отжимания ≈ 0,65, подтягивания ≈ 1. Задаётся у упражнения, `null` — собственный вес не считается. |
| **Объём** | Тоннаж подхода: (вес × снарядов + вес тела × доля) × повторы, ×2 если «на сторону». Вес тела — взвешивание этой тренировки, иначе последний замер до неё. Рост в объём не входит. Нет данных — объём неизвестен, а не ноль. Подходы на время объёма не имеют. |
| **День тренировки** | Дата старта по часам телефона (`date`): телефон присылает смещение пояса, сервер считает день. По нему — фильтры `--from`/`--to`. |
| **Сердечко** | Отметка владельца у упражнения в тренировке: очень понравилось (`liked`). |
| **Заметка владельца** | Текст владельца к упражнению в тренировке (`comment`); не путать с заметкой плана (`note`) и заметкой подхода. |
| **Замер тренировки** | Замер, привязанный к тренировке (`workoutId`): сделан во время неё или в течение 3 часов после. Его вес тела идёт в объём этой тренировки. |
| **Фото прогресса** | Снимок тела: когда снято (можно задним числом), ракурс (`front` / `side` / `back` или свой), заметка, тренировка. Удаляется в корзину. |
| **Рост** | В профиле, см. Агент видит его в `compare` рядом с весом тела. |
| **Админ** | Пользователь, который заводит других и ведёт общий справочник. |
| **Общий справочник** | Упражнения админа, видные всем (`shared`). У остальных к нему добавляются свои. |
| **Версия** | semver проекта + коммит: `0.2.0+5cdae85`. |
| **Рабочие подходы** | Сделанные подходы в основных блоках, без разминки и заминки. Мера нагрузки, сравнимая между упражнениями. |
| **Время под нагрузкой** | Сумма подходов на время; «на сторону» — на обе. |
| **Замена** | Упражнение подменено на ходу: сделанные подходы остаются со старым, новые — с новым, цель плана та же, в раскладке — `replacedFrom`. |
| **Предзаполнение** | Как в Hevy: значения из целевого подхода плана; чего в плане нет — из прошлого факта на том же номере подхода. Прошлый результат виден рядом. Правка одного подхода на другие не распространяется. |
| **Таймер отдыха** | Полоска с обратным отсчётом после отметки: отметка закрыла проход — отдых после прохода, иначе — после упражнения. В круге без отдыха в плане — открытый отдых, счёт вверх. Не блокирует, подсказка. Конец — вибрация и звук. |
| **Таймер / секундомер** | Ручные инструменты в шапке тренировки, как в Hevy: обратный отсчёт с пресетами и секундомер. |
| **Оценка** | Легко / Норма / Тяжело. Тап по оценке = подход выполнен с текущими (предзаполненными) значениями. В приложении светофором: зелёный / жёлтый / красный. |
| **Выполненное упражнение** | Все его подходы в тренировке отмечены. На экране тренировки — серая карточка со сводкой; переоткрывается для правки. |
| **Незапланированный блок** | Круг или заминка, добавленные во время тренировки (`addBlock`): в плане их не было, упражнения в нём — `added`. Круг встаёт перед заминкой, заминка — последней. |
| **Отметка** | Момент записи подхода. Из отметок — реальный порядок, темп, фактический отдых. |
| **Справочник упражнений** | Активные упражнения: общий справочник + свои. Стартовый набор из нескольких десятков базовых + добавленные по запросу. |
| **Источник упражнений** | exercises-dataset (1324 шт.) — откуда упражнения добавляются в справочник, с ru-названием. |
| **Медиа-пакет** | Картинки и gif из датасета, заменяемая папка, отдельно от справочника. |
| **Период статистики** | Окно, за которое считается нагрузка. По умолчанию — месяц. |
| **Звёздчатая диаграмма** | Нагрузка по частям тела за период: каждая ось — часть тела, по ней видны перекосы. |
| **Схема тела** | Силуэт спереди и сзади; мышцы, которые были в работе за период, подсвечены — чем ярче, тем больше нагрузки. |
